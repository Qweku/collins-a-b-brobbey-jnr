Security · University Systems

Tamper-Evident E-Voting Platform

Built for university-wide student elections. Every vote is written into a hash-chained ledger — each record cryptographically linked to the one before it — so any tampering breaks the chain and is immediately detectable. Voters authenticate through single-use magic links, with results and reminders delivered through queued SMS and email jobs.

Laravel 13Hash-chained ledgerMagic-link auth mNotify SMSGmail SMTPQueued jobs
Fintech · Payments

Cross-Bank Payment Verification Tool

A reconciliation layer that sits between transactions and two separate bank APIs — Prudential Bank and CalBank — each with different response shapes. An adapter pattern normalizes both into a single VerificationResult, so the rest of the application never has to know which bank it's talking to.

LaravelAdapter patternPrudential Bank API CalBank APIDTO normalization
Product · Mobile Money

Susu Digital Savings Circles

A mobile app concept and MVP plan for digitizing susu — the rotating group savings circles common across West Africa — with Mobile Money built in from day one, so contributions, payout order, and group trust are tracked digitally instead of on paper.
